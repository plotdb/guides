# Framework Documentation

本目錄記錄本專案所使用的開發框架，目的是讓 AI Agent 在未來協作工作階段能快速重建對框架的理解，無需從頭摸索。

## 使用方式

1. 讀 `index.md` — 取得各 scope 的一句話摘要與連結
2. 進入各 scope 目錄的 `index.md` — 查看模組清單與摘要
3. 進入各模組的 `index.md` — 閱讀 API、設計決策與重要細節

## 維護原則

- 每次有重要設計決策或 API 變動，在對應模組文件中補充，並更新上層 index 的摘要
- 模組不複雜時，細節直接寫在 `index.md`；複雜時拆多檔，由 `index.md` 指引
- 文件目的是幫助快速回憶，不是完整 API 手冊；側重非顯然的設計決策與跨模組關係
