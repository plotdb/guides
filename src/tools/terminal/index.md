# 終端機控制

從程式控制終端機的外觀與行為：改分頁標題、改分頁顏色、把控制序列送到正確的地方。

常見的使用情境是背景程序或 hook 想回報狀態 —— 例如同時開多個工作階段時，
讓每個分頁自己顯示在做什麼、現在是什麼狀態。這類程式碼有兩個獨立的問題要解決，
各自對應一份文件。

 - 要送什麼：控制序列的格式與能力邊界。詳見 [escape-sequences.md](escape-sequences.md)
 - 要送到哪：取得目標 tty，特別是自身沒有 controlling terminal 時。詳見 [tty-access.md](tty-access.md)


## 通則

控制序列寫錯不會報錯。終端機看不懂的序列就直接忽略，寫到錯的檔案描述子也只是沒有反應，
所以這類程式碼的失敗一律是靜默的。開發時要先建立一個能確認狀態的方法，
不要靠「看起來沒動」來推斷原因。

送出的內容多半是終端機專屬的擴充，不是標準。同一段序列在 iTerm2、Terminal.app、
tmux 底下的結果可能完全不同。跨終端機的程式要嘛偵測型別，要嘛接受在不支援的環境下無作用。
