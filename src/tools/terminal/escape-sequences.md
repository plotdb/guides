# 終端機控制序列

改分頁標題與分頁顏色所需的 OSC (Operating System Command) 序列，以及它們的能力邊界。

以下觀察來自 iTerm2 3.6.6 / macOS。標題序列是通用的，顏色序列是 iTerm2 專屬。


## 分頁標題

三種形式，差別在影響哪個欄位：

    printf '\033]0;標題\007'    # icon name 與 window title 同時設定
    printf '\033]1;標題\007'    # 只設 icon name (分頁名)
    printf '\033]2;標題\007'    # 只設 window title

結尾的 `\007` (BEL) 是終止字元，也可以用 `\033\\` (ST)。多數情況用 `\033]0;` 即可。

標題是純文字，無法上色。字串裡塞 ANSI SGR 顏色碼不會被解讀，會被當成一般字元或直接丟棄。
要在標題上表達狀態，只能靠文字本身或前置符號。


## 分頁顏色 (iTerm2 專屬)

三個通道分開送，每個通道 0 到 255：

    printf '\033]6;1;bg;red;brightness;255\007'
    printf '\033]6;1;bg;green;brightness;200\007'
    printf '\033]6;1;bg;blue;brightness;0\007'

還原成預設顏色：

    printf '\033]6;1;bg;*;default\007'

吃的是完整 RGB，不是 ANSI 十六色，所以配色不受調色盤限制。染色範圍是整個分頁，
不是標題文字 —— 這也是目前唯一能在分頁上表現顏色的手段。

其他終端機會忽略這組序列，不會產生錯誤或亂碼。


## 選色的注意事項

iTerm2 會把非作用中分頁的顏色調暗。同一個色碼在當前分頁清晰可辨，
在旁邊的分頁可能就跟背景糊在一起。這是實際使用時最容易誤判的地方 ——
設定當下看起來很好，切走之後才發現看不見。

淺色受影響最大。高飽和、中明度的顏色比較耐得住這層淡化。
測試時務必切到別的分頁回頭看，不要只看當前分頁。

另一個變因是 iTerm2 的 Appearance 主題設定 (Regular、Compact、Minimal)，
會改變分頁顏色的呈現方式與面積。同一組 RGB 在不同主題下的視覺強度差異明顯。


## 覆蓋與競爭

分頁標題是全域狀態，任何有寫入權限的程序都能改，最後寫的贏。
所以要注意有沒有別的東西也在寫：

 - shell 的 `precmd` / `PROMPT_COMMAND` 常會在每次顯示提示字元前重設標題
 - 終端機模擬器本身的設定可能鎖定標題格式，讓程式送的序列無效
 - 其他工具 (編輯器、多工器、CLI 應用) 也可能自行設定

程式送出的標題沒有生效時，先確認是不是被上述來源蓋掉，而不是序列寫錯。
iTerm2 的部分在 Preferences 的 Profiles 與 Appearance 兩處都有相關設定。
