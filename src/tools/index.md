# 工具使用注意事項

開發過程中會用到的外部工具，其行為上的陷阱與非顯而易見的限制。

這裡不是工具教學，而是「用了才知道」的那一類知識：官方文件沒寫、或寫了但要踩過才懂的部分。
判斷要不要寫進來的標準是，下次遇到同樣狀況時，這份筆記能不能省下重新查證的時間。

 - `terminal/`：終端機控制，escape sequence 與 tty 存取。詳見 [terminal/index.md](terminal/index.md)
 - `claude-code/`：hook、skill、設定的載入規則與限制。詳見 [claude-code/index.md](claude-code/index.md)


## 撰寫原則

記錄結論與判斷依據，不記錄過程。「試了 A 不行、改用 B」對讀者沒有價值，
「A 在什麼條件下會失敗，所以要用 B」才有。

驗證方式盡量寫下來。多數陷阱之所以難纏，是因為失敗時沒有明顯訊號，
知道怎麼確認狀態比知道結論更重要。

工具版本會變，行為也會跟著變。若某個結論是針對特定版本觀察到的，註明版本。
