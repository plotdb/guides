# Claude Code

自訂 Claude Code 行為時的注意事項：hook、skill、設定的載入規則與各自的限制。

以下觀察來自 2.1.228 版 / macOS。這些是實作細節，可能隨版本改變，
但失敗時的表現多半是靜默的，所以知道怎麼查證比記住結論重要。

 - hook：事件時機、執行環境、設定合併。詳見 [hooks.md](hooks.md)
 - skill：目錄結構、命名與載入限制。詳見 [skills.md](skills.md)
 - 設定與環境變數：載入時機與查證方式。詳見 [configuration.md](configuration.md)


## 查證方式

官方文件未涵蓋的行為，可以直接從安裝的執行檔找答案。它是打包過的 Node 應用，
字串與程式碼都在裡面：

    ls -l $(which claude)

檔案很大，用 `grep` 掃全檔會很慢，以 Python 讀進記憶體再用正規表示式搜尋比較實際。
搜尋環境變數名稱通常只會找到宣告表，要看實際行為得找呼叫點 ——
以功能相關的字串 ( 檔名、關鍵字 ) 為起點，往前後取一段上下文閱讀。

設定檔的完整 schema 也可以從這裡取得，包含未公開的欄位與其說明。
遇到「有沒有這個設定」的問題時，查 schema 比猜測可靠。
